# America 250 Etsy SEO Master Plan

Use this as the source of truth for Etsy and Printify listings. Etsy search works best when the title, tags, category, attributes, photos, price, shipping, and listing performance all support the same buyer intent. Do not copy the same title and tags to every product. Each design should target a slightly different search.

## Global Rules

- Put the strongest keyword phrase at the beginning of the title.
- Keep titles readable. Avoid stuffing every possible keyword into one title.
- Use all 13 Etsy tags. Use multi-word phrases when possible.
- Do not repeat the exact same phrase in title and every tag unless it is the main buyer phrase.
- Fill every relevant Etsy attribute: color, occasion, holiday, recipient, material, style, sleeve length, fit, room, capacity, etc.
- Use the first 160 characters of the description to repeat the main search intent naturally.
- Use one clean product photo first, then lifestyle mockups, design close-up, color/options image, size chart, care instructions, and personalization instructions.
- Listings for personalized designs need the word "custom" or "personalized" in title, tags, and description.
- Listings for 1976 birthday designs should target "born in 1976", "50th birthday", and "double celebration".
- Faith designs should target "faith and freedom", "Christian patriotic", and "one nation under God".

## Product Title Formula

Use the product word that matches the listing:

- Shirt: `America 250 Shirt`
- Sweatshirt: `America 250 Sweatshirt`
- Tote: `America 250 Tote Bag`
- Hat: `America 250 Hat`
- Mug: `America 250 Mug`

Example formula:

`[Main keyword + product], [1776-2026 or design phrase], [buyer intent], [gift/use case]`

## Listing Photo Order

1. Main lifestyle mockup with product clearly visible.
2. Design close-up.
3. Product color/options image.
4. Size chart or product dimensions.
5. Material and care image.
6. Personalization instructions, if applicable.
7. Shipping/processing note.
8. Additional lifestyle mockups.

## Etsy Listing Checklist

- Category matches product.
- All 13 tags are filled.
- Title begins with the most specific phrase.
- Description first line includes main keyword phrase.
- Personalization is enabled only where needed.
- Product photos are bright and not blurry.
- Attributes are fully filled.
- Price includes production cost, Etsy fees, transaction fees, and profit.
- Shipping profile is correct.
- Printify variants are checked before publishing.
